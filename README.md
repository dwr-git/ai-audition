# AI Звук

Звуковой редактор в браузере для подкастов, интервью и озвучки: многодорожечная запись, монтаж, эффекты и
сведение, помощник на вашей модели и проекты на вашем сервере (nginx + PHP, без Rust на сервере).

- Установка на сервер: [`studio/README.ru.md`](studio/README.ru.md); что нового — [`studio/CHANGES.ru.md`](studio/CHANGES.ru.md).
- Готовые сборки — в Releases (`ai-audition-build-N-ГГГГ-ММ-ДД.zip`), их делает GitHub Actions (`.github/workflows/studio.yml`).
- Основан на [SoundCraft](https://github.com/storytold/soundcraft) от команды ArtCraft (MIT OR Apache-2.0);
  его README — [`docs/README-upstream.md`](docs/README-upstream.md). AI Звук — не продукт ArtCraft и не
  несёт его знаков.

Audition — товарный знак Adobe. AI Звук не связан с Adobe и работает с обычными звуковыми форматами.
