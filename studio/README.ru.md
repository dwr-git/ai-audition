# AI-Audition — установка на сервер

Звуковой редактор в браузере: многодорожечная запись, монтаж, сведение и эффекты — для подкастов, интервью,
озвучки и аудиокниг. Со встроенным помощником на вашей локальной модели и проектами на вашем сервере.
На сервере нужны только **nginx + PHP + Ollama** (или другой сервер модели) — то, что у вас уже есть.
Ничего компилировать не нужно. Редактор полностью автономный: всё загружается из его папки, интернет и
сторонние сайты не нужны.

## Установка (5 минут)

1. **Скачайте готовую сборку.** GitHub → репозиторий `ai-audition` → справа **Releases** →
   верхняя «Сборка N — дата» (с пометкой Latest) → файл `ai-audition-build-N-ГГГГ-ММ-ДД.zip`.
   Какая сборка стоит у вас, видно в шапке панели помощника: «Модель: … · сборка N».
2. **Распакуйте** — внутри одна папка `ai-audition`.
3. **Положите её на сервер** рядом с остальными приложениями: `/app/src/ai-audition/`.
   Папку можно назвать как угодно — все пути внутри относительные. Помощник и хранилище сами найдут
   ваш `auth.php` на два уровня выше и через него — `config.php`, `.env`, адрес Ollama и модель.
4. **Папка для проектов создаётся сама**: `storage/ai-audition` рядом с корнем сайта.
   Проверка: `https://ваш-домен/ai-audition/api/files.php` → `{"ok":true,…}`.
5. **nginx и PHP — большие файлы.** Проект сохраняется на сервер одним файлом вместе со всем звуком, поэтому
   запросы бывают большими. Готовые блоки — в `nginx.conf.example`:
   - для `api/files.php`: **`client_max_body_size 210m;`** (не меньше `AI_AUDITION_MAX_MB`, по умолчанию 200 МБ)
     и `fastcgi_read_timeout 300s;`;
   - в PHP (`php.ini` или пул FPM): `post_max_size = 210M`, `upload_max_filesize = 210M`;
   - для `api/assistant.php`: `client_max_body_size 20m;` и `fastcgi_read_timeout 200s;`.
   Нужны файлы больше — поднимите `AI_AUDITION_MAX_MB` в `.env` и эти три числа вместе с ним.
6. **Откройте** `https://ваш-домен/ai-audition/`.

Обновление — то же самое: скачать новый zip и заменить папку (свой `studio/config.js` сохраните).
Каждая сборка лежит в своей папке `b/<номер>/`, а `index.php` открывает самую новую целую, поэтому
программа заливки не может смешать файлы двух сборок. Если заливаете по FTP, лучше включить «Перезаписывать всегда».

Для проверки без входа в систему на своём компьютере:
`AI_AUDITION_ALLOW_ANON=1 php -S 127.0.0.1:8080 -t ai-audition` и откройте `http://127.0.0.1:8080/`.

## С чего начинается

При первом запуске интерфейс русский, тема — **Фирменная**, открыт пустой проект «Без названия» (48 кГц,
24 бита). Звук можно открыть из «Моих проектов», кнопкой «С компьютера…» в той же панели, перетащить файл в окно
или через меню Файл › Импорт › Звук. Демо-песню, синтезированную самим редактором, открывает адрес `…/?demo`.

Браузер включает звук только после первого нажатия на страницу: если при воспроизведении тихо, щёлкните по окну.
Запись с микрофона просит разрешения браузера.

## Проекты и записи

- **Ctrl+S** сохраняет проект в «Мои проекты» на сервере (значок папки в панели помощника) одним файлом
  **.scraftz** — сам проект и весь его звук. Первый раз спросит имя, дальше сохраняет туда же.
  «Сохранить как…» — копия под новым именем.
- **Мои проекты**: список с датой и размером, поиск, открыть, переименовать, удалить (в корзину `.trash`).
  Хранятся проекты (.scraftz, .scraft) и записи: WAV/BWF/RF64, AIFF, FLAC, MP3, OGG/Opus, M4A/MP4/AAC, AC-3,
  CAF, MKA/WebM, а также MIDI. Сервер проверяет содержимое по первым байтам. Проект открывается вместо
  текущего (редактор спросит про несохранённые изменения), запись — добавляется в проект новой дорожкой.
- «С компьютера…» — открыть проект или добавить записи; добавленная запись сразу копируется и в «Мои проекты».
- У каждого пользователя своя папка. Проект с сервера сохраняется туда сам раз в две минуты, если в нём есть
  изменения и сейчас не идёт воспроизведение или запись. Если сохранить не удалось (нет связи, файл больше
  предела), копия остаётся в браузере, и панель предложит её открыть.
- **Сведение** (Файл › Свести микс, быстрые задачи «Скачать сведение WAV/FLAC») и другие экспорты (стемы, клипы,
  MIDI) **скачиваются в браузере**. Форматы сведения — WAV, AIFF, FLAC (MP3 редактор пока не пишет).

## Помощник

- **Совет** — объясняет, где найти функцию, разбирает проект, подсказывает обработку голоса и уровни. Ничего не меняет.
- **Сделай** — сам правит проект командами редактора: режет и склеивает, убирает тишину (Strip Silence),
  нормализует, ставит фейды, эффекты на дорожки (эквалайзер, компрессор, де-эссер, гейт, лимитер, реверберация…),
  создаёт и переименовывает дорожки, клипы и маркеры, сводит в файл и сообщает громкость (LUFS) и пик.
  Каждое действие отменяется (Ctrl+Z). Сколько шагов подряд делать и спрашивать ли перед удалением — «Настройки»
  внизу панели. Звук модель не слышит: она видит дорожки, клипы, маркеры и (если включён «глаз») снимок экрана с волнами.
- **Быстрые задачи** (значок с квадратиками) — в одно нажатие, на выделенные дорожки или на все:
  - **Убрать тишину** — вырезать паузы тише −45 дБ длиннее 0,5 с; если дорожка одна, оставшиеся фразы смыкаются
    с паузой 0,3 с (на нескольких дорожках клипы не сдвигаются, чтобы не разъехалась синхронность);
  - **Выровнять громкость** — нормализовать клипы по пику до −1 дБ;
  - **Подготовить к подкасту** — на голос срез низов 80 Гц, компрессор и де-эссер, на мастер — лимитер с потолком −1 дБ;
  - **Плавные края клипов**, **Голос громче на 3 дБ**, **Дорожка для голоса**, **Маркер здесь**;
  - сохранить, «Скачать сведение WAV/FLAC», новый проект — и готовые просьбы помощнику.
- **Быстрая строка — Ctrl+Shift+Пробел.**

### ИИ у выделения

Кнопка **ИИ** справа в строке меню (рядом с домиком) или **Ctrl+Alt+Пробел**. Текст в звуковом проекте —
это названия клипов, дорожек и маркеров и комментарии к дорожкам; с ними помощник и работает:

- выделены **клипы** — их названия; выделены **дорожки** — их названия и комментарий; ничего не выделено —
  **маркеры**; маркеров нет — проект целиком;
- в меню: понятные названия, исправить ошибки, короче, перевод; написать или улучшить комментарий дорожки;
  **главы с таймкодами**, **описание выпуска**, варианты названия, что в проекте. Можно написать свою просьбу.

Модель видит план всего проекта (дорожки, клипы со временем, маркеры), а работает с выделенным. Ответ сначала
показывается в окошке: **Применить к названиям** (по одному на строку, в том же порядке), **Записать в
комментарий дорожки**, **Копировать** или **Ещё вариант**. Отмена — Ctrl+Z. Задания для модели — в
`api/context.php`. Расшифровки речи в тексте в редакторе нет, поэтому главы и описание строятся по названиям и
маркерам, которые вы расставили.

## Оформление

Тема редактора — **Фирменная** (по умолчанию), **Светлая** или **Тёмная**: значок палитры в панели помощника
или «Установка › Настройки». Выбор запоминается в браузере. Домик справа вверху ведёт обратно на сайт
(адрес — `homeUrl` в `studio/config.js`).

## Шрифты

Отдельных шрифтов в сборке нет и не нужно: редактор рисует только свой интерфейс и названия (дорожек, клипов,
маркеров), а встроенные шрифты egui покрывают латиницу и кириллицу.

## Настройки в `.env` (необязательно)

| Переменная | Что делает | По умолчанию |
|---|---|---|
| `AI_AUDITION_DATA_DIR` | Где хранить проекты и записи пользователей | `storage/ai-audition` рядом с корнем сайта |
| `AI_AUDITION_MAX_MB` | Самый большой файл в «Моих проектах», МБ (столько же должны пропускать nginx и PHP, см. ниже) | 200 |
| `AI_AUDITION_MODEL` | Модель помощника (нужны tools; для «глаза» — картинки) | `GLOBAL_MODEL` |
| `AI_AUDITION_OLLAMA_URL` | Адрес Ollama или шлюза | `OLLAMA_IP:OLLAMA_PORT` |
| `AI_AUDITION_CONTEXT` | Размер контекста | `GLOBAL_MODEL_CONTEXT` или 32768 |
| `AI_AUDITION_TIMEOUT` | Сколько секунд ждать модель | 180 |
| `AI_AUDITION_MAX_TOKENS` | Длина ответа | 2048 |
| `AI_AUDITION_AUTH_FILE` | Путь к `auth.php`, если папка лежит не в `/app/src/` | ищется автоматически |
| `AI_AUDITION_TALERS_FILE` | `talers.php` кабинета для ИИ у выделения (цена операции и остаток) | `cabinet/talers.php` рядом с корнем сайта, если он есть |
| `AI_AUDITION_ALLOW_ANON` | `1` — без входа (только для проверки!) | выключено |

### Откуда помощник берёт модель

Главный источник — файл **.env** вашей системы. Помощник находит его сам: рядом с папкой приложения
и выше по папкам (обычно это `.env` в корне сайта или уровнем выше). Если .env лежит в другом месте,
укажите путь в переменной `AI_ENV_FILE`. Значения из .env важнее переменных окружения процесса:
если сервер запущен со старыми переменными, а .env поменяли, работает то, что написано в .env.

Порядок поиска (берётся первое найденное):

| Что | Где ищется |
|---|---|
| Адрес сервера модели | `AI_AUDITION_LLM_URL` → `LLM_URL`, `OLLAMA_URL`, `OLLAMA_HOST`, `OPENAI_BASE_URL` → `OLLAMA_IP` + `OLLAMA_PORT` → `$url_ollama` из config.php системы → `127.0.0.1:11434` |
| Модель | `AI_AUDITION_MODEL` → `GLOBAL_MODEL`, `LLM_MODEL`, `OLLAMA_MODEL`, `CHAT_MODEL`, `DEFAULT_MODEL` → `$global_model` из config.php → первая модель, которую отдаёт сам сервер |
| Размер контекста | `AI_AUDITION_CONTEXT` → `GLOBAL_MODEL_CONTEXT`, `LLM_CONTEXT`, `OLLAMA_CTXSIZE` → `$ollama_ctxsize` → 32768 |
| Ключ (если шлюз его требует) | `AI_AUDITION_API_KEY` → `LLM_API_KEY`, `OPENAI_API_KEY` |
| Протокол | `AI_AUDITION_LLM_API` или `LLM_API` = `ollama` / `openai`; без них определяется сам |

- **Любой сервер:** работает и с Ollama, и с OpenAI-совместимыми серверами (vLLM, GLM, LM Studio и
  другие). Адрес с `/v1` на конце считается OpenAI-совместимым. Если у адреса нет `/api/chat`
  (как у Ollama), помощник сам пробует `/v1/chat/completions`.
- **Любая модель:** имя модели сверяется со списком моделей сервера. Если такой модели там нет,
  берётся подходящая из списка. Если шлюз принимает имена-псевдонимы, которых нет в его списке
  (например `chat`), поставьте `LLM_MODEL_CHECK=0`.
- Если сервер не умеет вызывать инструменты, помощник сам переходит на текстовый протокол вызовов.
- **Как проверить:** наведите мышь на строку «Модель: …» в шапке панели помощника. Там написано,
  какая модель используется и из какой строки .env она взята. То же показывает адрес
  `api/assistant.php` в браузере.


## Если что-то не работает

| Признак | Что проверить |
|---|---|
| Редактор не запускается | Под полосой загрузки написано, какой файл не пришёл и почему |
| После заливки по FTP — старая версия | Программа заливки пропустила файлы того же размера: включите «Перезаписывать всегда» |
| Нет звука при воспроизведении | Щёлкните по окну редактора: браузер включает звук только после нажатия |
| В панели «Нужно войти в систему» | Вход в вашу систему в этом же браузере и на этом же домене |
| «Не удалось создать папку для файлов» | Создайте `storage/ai-audition` и дайте PHP право записи, или задайте `AI_AUDITION_DATA_DIR` |
| Проект не сохраняется, ошибка 413 | `client_max_body_size` для `api/files.php`, `post_max_size` и `upload_max_filesize` в PHP, `AI_AUDITION_MAX_MB` — см. выше |
| Помощник: ошибка 413 / 504 | `client_max_body_size 20m` / `fastcgi_read_timeout 200s` для `api/assistant.php` — см. `nginx.conf.example` |

## Для разработчика

- Сборку делает GitHub Actions (`.github/workflows/studio.yml`) на каждое изменение ветки `main`.
- Мост редактора: `apps/soundcraft-web/src/web/bridge.rs` — `window.aiaudition.request(метод, параметры)`,
  те же методы, что у канала управления (`crates/ui-egui/src/control.rs`). В консоли браузера:
  `await aiaudition.execute('track.new', {count: 1, format: 'mono', name: 'Голос'})`.
- Сохранение на сервер: обработчик выдачи файлов движка (`io::set_deliver` в `apps/soundcraft-web/src/web.rs`)
  отдаёт сохранённый проект `.scraftz` странице событием `aiaudition:save` → `api/files.php`; остальное скачивается.
- Русский интерфейс: таблица `crates/ui-egui/src/ru.tsv` (английский текст → русский) и переводчик
  `crates/ui-egui/src/ru.rs`, подключённый к egui через крючок `egui::set_text_translator` (egui лежит в
  `vendor/egui` с этим единственным добавлением).
- Основано на открытом проекте SoundCraft (github.com/storytold/soundcraft, MIT OR Apache-2.0) от команды
  ArtCraft; лицензии — в `NOTICE` и `LICENSE-*`.
